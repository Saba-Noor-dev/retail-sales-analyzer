# Retail Sales Analyzer

A Python-based data analysis project that processes retail sales data from a CSV file and generates a sales performance summary.

## Features

- Reads sales records using Python CSV module.
- Validates data and handles invalid or missing values.
- Calculates total revenue, quantity sold, and number of orders.
- Calculates average order value.
- Identifies the best-selling product.
- Finds products and categories with the highest revenue.
- Analyzes monthly revenue and sales quantity.
- Uses reusable Python functions.
- Handles missing CSV files.

## Technologies Used

- Python
- CSV Module
- Dictionaries
- Functions
- Exception Handling

## How to Run

1. Clone or download this repository.
2. Make sure Python is installed.
3. Keep `sales_data.csv` in the same folder as the Python script.
4. Run:

```bash
python main.py
```
